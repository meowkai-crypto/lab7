# Лабораторная работа №7 (C++)

Этот репозиторий содержит выполненные задания №1–5 по лабораторной работе на языке C++ (стандарт C++17). 
В работе рассматриваются методы обработки строк, работа с текстом, алгоритмы и валидация данных.

## 📋 Список заданий:

*   **Задание 1: Подсчёт слов в строке**
    *   Программа разбивает введенную строку на слова и подсчитывает их количество. 
    *   Учитываются разделители (пробелы, знаки препинания).
*   **Задание 2: Проверка строки на палиндром**
    *   Проверяет, читается ли строка одинаково слева направо и справа налево.
    *   Игнорирует регистр букв и знаки препинания.
*   **Задание 3: Шифр Цезаря**
    *   Реализует алгоритм шифрования и дешифрования текста сдвигом букв алфавита.
*   **Задание 4: Валидация входных данных**
    *   Проверка корректности введенных пользователем данных (Email, номер телефона, URL-адрес) с помощью регулярных выражений (Regular Expressions).
*   **Задание 5: Форматирование таблицы**
    *   Вывод текстовых данных в виде аккуратной, выровненной таблицы в консоли.

## 🛠 Требования для сборки

Для компиляции программ вам понадобится:
*   Компилятор с поддержкой стандарта **C++17** (например, `g++`, `clang++` или MSVC).
*   Терминал (командная строка) для запуска.

Каждый файл (например, `zad1.cpp`, `zad2.cpp` и т.д.) представляет собой независимую программу. 
Их можно компилировать и запускать по отдельности.

**Пример компиляции и запуска первого задания:**

1. Откройте терминал в папке с файлами.
2. Скомпилируйте файл:
   ```bash
